# UI GUIDELINES

## Design Goals

- Professional
- Clean
- Pet-friendly
- Consistent between Admin and Provider

---

## Page Layout

Every dashboard page follows:

Page Header
↓
Action Bar
↓
Filters
↓
Main Content
↓
Pagination

---

## Tables

Use same style across system.

Structure:

- Search
- Filter
- Table
- Pagination

Actions placed in rightmost column.

---

## Forms

Structure:

Label
Input
Helper Text
Error Message

Rules:

- Labels above fields
- Full width inputs
- Consistent spacing

---

## Cards

Use cards for:

- Analytics
- Summary
- Statistics

Do not place forms inside summary cards.

---

## Dialogs

Use same dialog pattern:

Header
Description
Body
Footer Actions

Primary Action Right
Cancel Left

---

## Status Colors

Booking Status

PENDING
Yellow

CONFIRMED
Blue

IN_PROGRESS
Purple

COMPLETED
Green

CANCELLED
Red

---

## Analytics

Use:

- Line Chart
- Bar Chart
- Pie Chart

Always provide:

- Loading State
- Empty State
- Error State

---

## Responsive

Desktop First

Breakpoints:

sm
md
lg
xl

All tables should support mobile scrolling.
